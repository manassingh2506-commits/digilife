# DigiLife

A Minimal OLED redesign concept for a DigiLocker-style document experience.

## Hackathon prototype

This repository is the starting point for the DigiLife frontend/backend prototype. Government verification is represented as a demo flow unless an authorized government API is integrated.

## Planned stack

- Next.js / React frontend
- Node.js / API routes
- Supabase authentication, PostgreSQL and storage
- AI document search
- Secure document-sharing demo flow

## Design

The UI is based on the DigiLife Minimal OLED design created in Figma.
